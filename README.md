# HDR Gradients

An Android app showcasing HDR (High Dynamic Range) gradients across various
color spaces and bit depths. The app renders a vertical stack of gradients
demonstrating how the device handles the different color spaces and pixel
formats to test the quantization and maximum brightness of your display.

Color Spaces: ACES, BT.709, BT.2020 (linear, PQ, HLG), Display P3, sRGB,
Extended sRGB.  
Bit Depths: 16-bit float (RGBA_F16), 10-bit (RGBA_1010102), 8-bit (ARGB_8888)

Requires Android 14+.
